## 🧪 Hands-on Labs

### Enterprise SOC Home Lab

Building and managing a virtualized cybersecurity lab to simulate a small enterprise environment, practice security monitoring, investigate incidents, and understand attack techniques from both offensive and defensive perspectives.

**Lab Infrastructure:**
- **Ubuntu Server + Wazuh SIEM** — Centralized security monitoring, log collection, endpoint visibility, alert detection, and investigation.
- **Windows Server** — Enterprise environment setup, Active Directory, user and access management, and Windows security policies.
- **Windows 11 Endpoints (2)** — Two separate user environments connected to the lab for endpoint monitoring, authentication analysis, and security event investigation.
- **Microsoft Defender** — Endpoint protection, threat detection, and investigation of suspicious activity.
- **Kali Linux** — Controlled attack simulations, network reconnaissance, and security testing against lab machines.
- **VirtualBox** — Virtualized infrastructure connecting all lab systems within an isolated testing environment.

**Practical Objectives:**
- Deploy and configure Wazuh SIEM on an Ubuntu Server.
- Integrate Windows endpoints and collect security telemetry.
- Monitor Windows authentication events, system activity, and suspicious behavior.
- Explore Microsoft Defender endpoint protection and detection capabilities.
- Simulate attacks using Kali Linux in a controlled environment.
- Investigate generated alerts, correlate events, and identify indicators of compromise (IOCs).
- Practice incident triage, threat detection, and response workflows.
- Document findings, configurations, and investigation procedures.
